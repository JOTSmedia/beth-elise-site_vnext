# Beth Elise Psychic – website (deploy-ready)

This folder is the finished, static Beth Elise Psychic website, ready to go live on GitHub Pages.

- GitHub repo: JOTSmedia/beth-elise-site
- GitHub Pages setting: deploy from the `main` branch, root folder (`/`)
- Live address: https://jotsmedia.github.io/beth-elise-site/

## How to publish

John uploads this folder by replacing the repo contents through the GitHub website (Add file > Upload files), then commits to `main`.

Include the hidden `.nojekyll` file. It stops GitHub from changing files during publishing. On a Mac, press Cmd+Shift+. (period) in Finder to show hidden files so it can be selected.
